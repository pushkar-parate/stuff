Networking Devices

Network Interface Card [NIC]

It is the card which provides interface for network connection to devices. Installed in Motherboard. Contains the MAC and ARP resolver cache. Can be wired or wireless. RJ-45 is most common Ethernet Cable and port in NIC.

MAC is a alphanumeric unique address assigned to each NIC by the manufacturer. ARP cache resolves IP to MAC address mapping.

We can also tell what Adapetr is associated with the MAC as shown in the image.

Hub

Broadcast connection device. One input port and multiple output ports. Does not filter data and cannot be configured. Sends packets to all connected devices, making it less secure but inexpensive.

Switches

Intelligent and configurable networking device. Forwards data only to the intended device, reducing traffic and improving security. More expensive than a hub, with multiple ports typically ranging from 8 to 64.

Repeater

Regenerates and strengthens weak signals to extend communication over long distances without significant signal loss.

Access Point

Device that provides wireless connectivity to devices on a network. Connects wireless devices to a wired LAN using Wi-Fi. Commonly used to extend wireless coverage in homes, offices, and campuses.

Router

Networking device that connects different networks and forwards data packets between them. Uses IP addresses to determine the best path for data transmission. Commonly used to connect a local network to the Internet.

Mordern home routers have buil-in Access Point to provide connectivity wirelessly while Router does Routing work.

DHCP Servers

DHCP vs BOOTP
Feature BOOTP DHCP
IP Assignment Static (pre-configured by admin) Dynamic (leased from a pool)
Flexibility Limited; requires manual updates Highly flexible; supports renewal and reallocation
Address Leasing Not supported Supported
Configuration Options Basic (IP, gateway, subnet mask, boot file) Rich (IP, subnet, gateway, DNS, lease time, more)
Use Case Diskless workstations booting OS from server Modern networks with mobile, dynamic devices

BOOTP is an older protocol that assigns static IP addresses and does not support leasing. DHCP is its successor, providing dynamic IP allocation, lease renewal, and additional network configuration options.

BOOTP is mostly obsolete and found only in legacy systems, while DHCP is the standard in modern networks.

DORA Process

DHCP uses the DORA process: Discover, Offer, Request, and Acknowledge.

The client broadcasts a Discover message to locate DHCP servers. A server responds with an Offer containing an available IP address. The client sends a Request for the offered address, and the server completes the process with an Acknowledge message confirming the lease.

Lease Time and Renewal

DHCP assigns IP addresses for a specific lease period. At 50% of the lease duration (T1), the client attempts to renew the lease with the original DHCP server. At 87.5% of the lease duration (T2), if renewal fails, the client broadcasts a request to any available DHCP server. If the lease expires, the client must stop using the address and obtain a new lease through the DORA process.

APIPA

It is a static and manual form where the Windows provides the IP lease.

The IP range assigned is from 169.254.0.0 / 16 and A Subnet Mask of 255.255.0.0 and 65534 usable hosts.

IPv4 Addressing

It has 4 set of bytes forming a 32 bit Unique Address assigned in a Network. In each octet numbers range from 0-255.
This was introduced by IANA [Internet Assigned Numebers Authority].

Reading IPv4 Address

Network Part

It is the part of the IP which does not change in a network and identifies the subnet of uniquely.
10.194.199.188
10.195.199.188
Two different computers in different subnets.

Host Part

It is the part which identifies the device in the same network and two devices in a network have different Host parts but same Network Part.
It may vary in range 1-254 and can be known using Subnet Masks.
192.168.32.225

Subnet Masks

It is what tells that which is Host Part and which is Network Part. It can be also used to determine size of a network.

255.255.255.0 Usually for Private or Local Area Networks 255.255.0.0 Usually for Bigger networks like MAN

The 0 part will be Host Part in the IP Address. And 255 will be the Network Part in IP Address.
Network masks can be written in CIDR Notation also.

CIDR Notation or IP Prefix-Length

IPv4 is 32-bit address comprising 4 sets of 8-bits or 1 Byte. Prefix length is the number of bits entitled to network part of an address. by which we can instantly tell its network size. It does not tell IP Class

Bigger CIDR = Less Network Size and vice-versa

Class A IP

These are like WAN having significant Range: 1.0.0.0 to 126.255.255.255. Default Subnet Mask: 255.0.0.0.

Number of Networks: 126, Number of Host 16 Million +
Used by: Very large organizations, ISPs, or backbone providers.

Class B IP

These are like MAN having lesser Range: 128.0.0.0 to 191.255.255.255. Default Subnet Mask: 255.255.0.0.

Number of Networks: 16,384 Hosts: 65,000+
Used by: ISPs, government agencies like NASA or ISRO.

Class C IP

These are your common LAN or PAN with low Range: 192.0.0.0 to 223.255.255.255. Default Subnet Mask: 255.255.255.0.

Number of Networks: Over 2 million Hosts: 254
Used by: Small organizations and local networks.

Class D IP

Range: 224.0.0.0 to 239.255.255.255.

These are Reserved Multicasting IP Addresses used by service providers or broadcasters. It does not require a subnet mask since multicasting doesn’t rely on host-specific communication — the data is broadcast to multiple recipients simultaneously.

Class E IP

Range: 240.0.0.0 to 255.255.255.254.

These do not need a subnet mask and are Reserved for Research and Development purposes by IANA.

Loopback IP

Range: 127.0.0.0/8

These IPs are used for communication within your own machine for diagnostics.

Practical Uses
  • Local testing — Run a local web server (e.g., localhost:3000) to test code without putting it on the internet.
  • Networking checks — Pinging 127.0.0.1 confirms your TCP/IP stack is working.
  • Internal communication — Apps communicate on the same machine without external traffic.
  • Security isolation — Services can bind only to 127.0.0.1 to ensure they aren’t publicly accessible.

These addresses are not meant for networking but are used to maintain internal security and testing on your own system.

Broadcast IP Address

Address: x.x.x.255

This is a Reserved IP Address for Limited Broadcast — it refers to "everyone" on the network. It’s used to broadcast messages to all hosts on a network. It is not a subnet mask or a valid assignable IPv4 address.
All Host Bits are set to value 255. Example:
10.19.94.255
255.255.255.255
169.254.255.255

Common Uses
  • DHCP Discover — When a device joins a network without an IP, it sends a broadcast to 255.255.255.255 asking for a DHCP server.
  • Wake-on-LAN / Network discovery — Used for tools that need to reach all hosts locally.
  • Diagnostics — Network troubleshooting and broadcast testing.

Multicast IP Address

Address: 224.0.0.0 to 239.255.255.255

This is a Reserved IP Address for Multicast — it refers to "a group" on the network.
All IP in this range are multicast regardless of broadcast rule. Example:
226.0.0.0
238.1.255.255
225.255.255.255

APIPA (Automatic Private IP Addressing)

Range: 169.254.0.0 / 16
Subnet Mask: 255.255.0.0 (/16)

When a computer fails to contact a DHCP server, it automatically assigns itself an IP in this range using APIPA. This allows limited local communication without internet connectivity.

Transmission Modes

Simplex Mode

One node can only send and other can only receive through the channel. Example: monitor output.

Half-Duplex Mode

Both nodes can send and receive but in turns. Example: walkie-talkie.

Full Duplex Mode

Sending and receiving is simultaneous. Example: phone calls.

Digital Transmission

When data travels along wires it is in ANALOG FORM. After processing in computer, it becomes DIGITAL FORM (01010101).

Digital-to-Digital Conversion

Conversion of digital data to analog signals for transmission. Types: Unipolar, Polar, Bipolar.

UniPolar [NRZ]

1 → +V, 0 → 0V. Concept: Only one polarity is used.
Pros: Simple, Cheap.
Cons: DC component needed, Poor Sync.
Example: TTL circuits.

Polar

Uses positive and negative voltages, thus has three levels: 1 0 -1. Types: NRZ, RZ, Manchester.
Pros: Better Sync, No DC Component needed.
Example: Ethernet, USB.

BiPolar

Eliminates DC problem, maintains syncing.
Types: AMI, Pseudo-Ternary.
Example: T1/E1 lines.

BiPolar [AMI]

There are three levels: +, 0, -. But the 1 is represented alternatively by + and - voltages. While 0 is by 0V.

BiPolar [PsuedoTernary]

It is the same as AMI but here 1 is treated 0 and 0 is treated as 1.

Overall Summary

Type Voltage Levels Example Synchronization DC Component Usage

Transmission Media

Common Terms

Bandwidth

Higher bandwidth → higher transmission rate.

Interference

Disturbance by unwanted electromagnetic signals.

Transmission Impairment

When received signals differ from original due to attenuation, distortion, or noise.

Attenuation

Loss of signal strength over distance.

Distortion

Loss of data due to frequency differences.

Noise Interference

Addition of unwanted signals.

Guided / Wired Media

Physical cables for data transmission (Bounded Media).

Twisted-Pair Cable

Most used in telecommunication and Ethernet. Types: STP, UTP.

RJ Connectors

Family of connectors for telephone and Ethernet wiring.

Coaxial Cable

Used for data, video, voice. Expensive, multiple layers to reduce interference.

BNC Connectors

Most common connector for coaxial cable.

Optic Fiber Cable

Glass strands transmit light pulses. High speed, long distance. Used in global Internet backbone.

Unguided / Wireless Media

Also called Air Media. Uses electromagnetic waves.

Radio Waves

Low frequency, penetrate walls. Used in radio, walkie-talkies. 20kHz – 300Hz

Microwaves

Straight line travel. Used for cellular, Wi-Fi, 3G/4G/5G. 1GHz – 1000GHz

Infrared Waves

High frequency, blocked by objects. Used in remote controls, night vision, motion detection. 300GHz – 400THz
